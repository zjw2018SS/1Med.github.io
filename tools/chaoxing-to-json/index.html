chaoxingRedo

这是面向用户直接安装的学习通油猴脚本。脚本在学习通作业结果页识别题目，支持复制、下载 JSON，并跳转本站做题页本地重做。

安装/更新油猴脚本 安装本地构建产物 使用说明

开发入口

源码已经迁移到 tools/chaoxing-to-json/src，使用项目统一的油猴构建框架。

本地安装测试：npm run chaoxing:dev；热更新调试：npm run chaoxing:hmr；发布构建：npm run chaoxing:build。

chaoxing:hmr 生成的 dev 脚本依赖本地 Vite 模块注入，在学习通页面可能被安全策略拦截。验收脚本是否能在学习通加载时，请优先安装本地构建产物。
